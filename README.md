

# California Housing Price Prediction | Machine Learning

A Machine Learning project that uses **Python and Linear Regression** to predict California house prices based on median income.

## Project Overview

This project demonstrates an end-to-end machine learning workflow, from data exploration and preprocessing to model training, evaluation, and prediction.

The objective is to understand how machine learning regression models can be applied to real-world housing price prediction problems.

## Problem Statement

Predict median house values in California using the California Housing dataset and a Linear Regression model.

## Dataset

- **Dataset:** California Housing Dataset
- **Source:** Scikit-learn
- **Target:** Median House Value
- **Type:** Supervised Machine Learning – Regression

Dataset sources:
- [Scikit-learn Documentation](https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset)
- [Download Dataset](https://ndownloader.figshare.com/files/5976036)

## Project Workflow

1. Load the California Housing dataset.
2. Explore and understand the dataset.
3. Perform data inspection and preprocessing.
4. Select the input feature and target variable.
5. Visualize the relationship between the variables.
6. Split the dataset into training and testing sets.
7. Train a Linear Regression model.
8. Generate predictions using test data.
9. Evaluate model performance.
10. Visualize actual versus predicted values.

## Model Development

**Algorithm:** Linear Regression

The model learns the relationship between the selected input feature and the target variable to estimate house prices.

## Model Evaluation

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
- Root Mean Squared Error (RMSE), where calculated

Actual and predicted values are also visualized to understand model performance.

*Refer to the Jupyter Notebook for the actual evaluation results and visualizations.*

## Installation and Usage

Clone the repository:

```bash
git clone https://github.com/Sandy7999/California-Housing-Price-Prediction-Linear-Regression.git
```

Navigate to the project directory:

```bash
cd California-Housing-Price-Prediction-Linear-Regression
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `California_Housing_Price_Prediction.ipynb` and run the cells.
